# Music Finder Bot

Telegram-бот: поиск песен, эффекты, редактор тегов и посты в канал.

## Как бот определяет, что делать

| Что прислали | Что делает бот |
|---|---|
| Аудиофайл (mp3, m4a, wav...) | Меню эффектов (speed up / slowed, reverb, 8D) и изменение тегов |
| Голосовое, видео, кружок | Находит песню (Shazam) и присылает аудиофайл |
| Ссылка (YouTube, TikTok, Instagram...) | Находит песню и присылает аудиофайл |
| Текст | Сразу присылает найденный трек аудиофайлом, под ним кнопки с другими вариантами |
| `/start` | Меню функций |
| `/post` | Пост в канал с кнопками (только для админов) |

Под каждым присланным треком стоит подпись со ссылками на каналы (см. `CAPTION` в начале `bot.py`).

## Эффекты и теги

- **Скорость**: пресеты 0.5x–0.9x (slowed), 1.1x–2x (speed up) или своё значение от 0.25 до 3. Тон меняется вместе со скоростью, как в обычных slowed / sped up ремиксах.
- **Reverb** и **8D** (лучше слушать в наушниках). Эффекты можно комбинировать.
- **Теги**: при загрузке аудио бот берёт название и исполнителя из файла (или из имени файла вида `Исполнитель - Название`) и сохраняет их в результате. Кнопка «🏷 Теги» меняет их, можно и без эффектов.
- **Обложка**: кнопка «🖼 Обложка», затем картинка (фото или файл). Бот обрезает её до квадрата, вшивает в mp3 и ставит миниатюрой в Telegram. Если обложку не менять, остаётся та, что была в файле.
- У найденных треков обложка ставится автоматически (из Shazam или с источника).
- Результат приходит в mp3 с теми же (или изменёнными) названием и исполнителем.

## Посты в канал

1. Добавь бота в канал администратором с правом публикации.
2. Укажи `CHANNEL_ID` (`@username` или числовой id) и `ADMIN_IDS` (твой Telegram id, его показывает @userinfobot).
3. Отправь `/post` или нажми «📢 Пост в канал» в меню: пришли пост, затем кнопки, проверь превью и опубликуй.

Формат кнопок: одна строка — один ряд, `Текст - https://ссылка`. Несколько кнопок в ряду разделяются знаком `|`.

## Локальный запуск

Нужны Python 3.10–3.12, [ffmpeg](https://ffmpeg.org/download.html) в PATH и токен от [@BotFather](https://t.me/BotFather).

```bash
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env            # заполни переменные
python bot.py
```

## Деплой на Render

В проекте есть `Dockerfile` (с ffmpeg) и `render.yaml`.

1. Залей репозиторий на GitHub (`.env` в него не попадёт).
2. На [render.com](https://render.com) создай сервис с runtime **Docker** (Background Worker или Web Service).
3. Добавь переменные окружения `BOT_TOKEN`, `CHANNEL_ID`, `ADMIN_IDS`.
4. Deploy.

Бесплатный Web Service засыпает через 15 минут без запросов: настрой пингер (например, UptimeRobot) на адрес сервиса. Бот сам поднимет мини-сервер на порту из `PORT`.

### Откуда бот берёт аудио

Сначала ищет на YouTube, затем на SoundCloud. Если один источник не работает (например, YouTube блокирует сервер), бот сам пробует следующий. Порядок задаётся переменной `SEARCH_SOURCES` (например, `soundcloud,youtube`). Если скачать не вышло, бот пишет причину ошибки.

### Если YouTube не даёт скачивать

Серверные IP часто блокируются (ошибка `Sign in to confirm you're not a bot`). Решение: экспортируй `cookies.txt` из браузера (расширение «Get cookies.txt LOCALLY»), загрузи его в Render как **Secret File** с именем `cookies.txt` и добавь переменную `COOKIES_FILE=/etc/secrets/cookies.txt`. Не публикуй этот файл на GitHub.

## Ограничения

- Telegram не даёт боту скачивать файлы больше 20 МБ и отправлять больше 50 МБ.
- Треки длиннее 10 минут бот не скачивает.
- Если ссылки перестали скачиваться, обнови yt-dlp (на Render достаточно пересобрать образ).
- Сессии хранятся в памяти: после перезапуска старые кнопки перестанут работать.
- Пост поддерживает одно сообщение (альбомы из нескольких фото не копируются).
- Распространение чужих треков может нарушать авторские права, а канал и хостинг могут получить жалобы. Ответственность на владельце бота.
